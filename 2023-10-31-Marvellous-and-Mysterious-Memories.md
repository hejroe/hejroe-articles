# Marvellous and Mysterious Memories

Memory for me is “a record of approximate state”. At least this is the definition I have formed that has proved useful over the years. This does not cover all aspects associated to memory. There is the retrieval, deletion, addition and updating aspects that deal with memory but are not memories themselves. There are also other mechanisms at play that morph, corrupt and erode memories.

Let us start by thinking what function memory actually performs. In the simplest of terms it allows for a comparison function. That is, is the recorded state the same as the currently observed state? That is it. It really is that simple, at least in explaining why memory is useful. 

To explain this more detail let’s run through an example of how this can work. Memories are formed by taking in sensory input and “storing” them by mechanisms we do not fully understand. But we do know that memories are stored, our existence relies on it. Take for an example the ability to spot movement, a physical object operating in three dimensions. In this simplest of tasks a state of a thing observed has to be retained. It cannot be prone to fluctuations for no apparent reason. As soon as the input changes enough to trigger the sensitivity for a change in state, then we can say that movement has been detected. What the actual tipping point is seems to vary from person to person. The same is also assumed for other optical systems. 

This most primitive function of memory can then act as the basis for more complex forms of memory. 

In thinking about memory a little more we could easily define different sorts of memory. Ever walk into a room and forget the thing you came into the room for? For many, myself included, this is a daily event. It does not take long before you start to realise that there are different sorts of memory that seem to work in different ways. The function is the same but the manifestation can be quite different. 

Running is something that I do a fair bit of. In fact my route is quite deliberate as I like to set myself a challenge. As you would expect the path I take is well trodden. So much so that I can run it in my thoughts as I drift off to sleep. At times I will then feel the muscles in my legs twitch subconsciously as I lay in bed. When this first happened, it took me a little by surprise. I was instantly reminded of a dog chasing squirrels while they slept. This seemingly involuntary physical response to just the playing back of a remembered scene was very interesting. 

Just where does memory live? Is it in your neo-cortex, nervous system, DNA/RNA even? Just how does a cell know where it supposed to be and what it should contain? In reality it would seem that memory exists in all of those places and likely far more besides. For instance, the development of a human is riddled with biological mechanisms that lay dormant until a certain set of conditions is met. 

The natural world also offers some amazing examples of different forms of memory at work. The Monarch butterfly is one where their migratory path takes around three generations to complete. A “returning” Monarch butterfly would never have been there before and yet they all get back to the same place at the same time. 

Another aspect of memory that seems incredibly important is that of compression. Despite the claims of some there is a limit to how much someone can remember. Just the physical limit of each atom is something that cannot be ignored. If we were able to remember everything with total clarity, then our brains would soon fill up with a lot of stuff that would not prove very useful. 

Another very important aspect of memory to consider is that it is always used by something else. It does not seem to exist in isolation. It always seems to appear as a mechanism to be used by something else. Is it possible for a memory to be formed through some chaotic process? Dreams may fit that description and there is more to be said on their specific nature. But that will have to wait for another time.
